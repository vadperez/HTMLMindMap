MindMap tutorial

This map opens the first time you start MindMap. Click any topic: its details and notes appear in the pane on the right. Edit it freely: it is your own copy, and nothing is saved unless you press Ctrl+S. F1 lists every shortcut. File › Tutorial brings this map back.
  • Your maps are files
    Every map is one HTML file on your own disk. It holds the map and a copy of the editor, so double-clicking it opens it in Chrome even without this app. Nothing is uploaded anywhere.
    • Open — Ctrl+O
      Opens a MindMap .html file, or imports MindManager (.mmap), OPML, FreeMind, Markdown, indented text or JSON. You can also drop a file on the window.
    • Save — Ctrl+S
      The first time, Chrome asks where to save the map. After that Ctrl+S writes straight into the same file. Ctrl+Shift+S saves a copy under another name.
    • File › Recent
      Reopens the maps you opened or saved here. Chrome may ask once more for permission to read the file.
    • Autosave
      Every few seconds a copy of your unsaved edits is kept on this computer. If Chrome closes, the map offers to restore them the next time you open it. Diagnostics lists the copies.
  • Build the map
    • Enter — new topic after this one
    • Tab or Insert — new subtopic
    • F2, double-click, or just type — edit the title
      Enter finishes, Esc cancels. Typing on a selected topic replaces its title.
    • Drag, Ctrl+M, Ctrl+↑ / Ctrl+↓ — move
      Drag a topic onto another to make it a subtopic, or onto its top or bottom edge to place it before or after. Ctrl+M searches for the new parent. Ctrl+↑ / Ctrl+↓ moves among siblings.
    • Ctrl+Z / Ctrl+Y — undo / redo
    • Paste an indented list
      Copy an indented list from any document and press Ctrl+V on a topic: every line becomes a topic at its level.
  • See as much as you need
    • Levels — Alt+1 … Alt+6, Alt+0 for all
      The Levels buttons in the toolbar set how deep the whole map is open.
    • Select this topic and press +
      + opens one more level below the selected topic, − closes one. The rest of the map stays as it is, and the toolbar then reads “Levels · custom”. You can also click the small +/− circle at the edge of a topic.

    • Space folds · * unfolds everything below
    • Focus — Ctrl+Shift+F
      Shows only the selected branch. Esc returns to the whole map.
    • Panes
      The three buttons next to Levels show or hide the outline, the map and the details pane. The button after them gives the map the whole window.
    • Search — Ctrl+F
      Finds topics by title, DOI, authors, journal, notes and abstracts.
  • Reorganize with the Shelf
    The Shelf (right pane, below the details) parks branches while you rearrange a large map. It is saved with the map.
    • Detach — Ctrl+D
      Moves the selected branch to the Shelf. Dragging a topic onto the Shelf does the same.
    • Attach or Return
      On a Shelf card, click Attach, then click the topic that should become its parent (Shift+click places it after that topic). Return puts it back where it came from.
  • Papers and references
    A reference topic keeps one paper together: title, link, DOI, authors, year, journal, volume, issue, pages and abstract. Switch any topic between Topic and Reference at the top of the details pane.
    • Deep learning
      doi:10.1038/nature14539
      Example reference. Its authors, journal and pages are still empty: select it and click Look up in the details pane to fill them in from Crossref (needs internet; only the DOI is sent).
    • A paper filed in two places — 2×
      The same paper (same DOI) filed under two topics shows 2×. Click the badge to highlight every copy; copies inside folded topics are counted on the folded topic as ◆N.
      • Deep learning
        doi:10.1038/nature14539
    • Orphan references — ∅
      A reference that is not filed under a topic — on the Shelf, directly under the central topic, or inside another reference — is marked ∅. The status bar counts them; click it to highlight them all.
    • Reference lists
      File › Reference list (or right-click a topic): APA 7, Vancouver, Harvard, Chicago author-date, Nature or Simple. Copy it into Word, or save it as Word (.docx), HTML or text. File also exports RIS and BibTeX.
  • Colours and the central topic
    • Branch colours
      Main topics get their own colours automatically. In the details pane any topic can get one of 10 colours or any colour of its own, passed on to the topics below.
    • Each subtopic its own colour
      Ticked for this topic (details pane, or right-click), so its subtopics are coloured independently.

    • Replace the central topic
      Delete on the central topic, or right-click a main topic › Make it the central topic: that main topic takes its place and the others move under it. Shift+Delete on any other topic removes only that topic; its subtopics move up one level.
  • Print and export — Ctrl+P
    Every layout has a preview. Letter paper by default; print any number of levels, or “As on screen”.
    • Map
      The drawn map on one page; says so when the text would become too small.
    • Outline
      Numbered text, with authors, DOI and abstracts if you want them.
    • Atlas
      An overview page, then each branch as deep as fits, with “→ p. N” where a branch continues.
    • Poster
      A large map tiled over Letter sheets with 0.5 in glue strips, plus a guide sheet that shows how the sheets go together.
    • Other formats
      File menu: OPML, Markdown, RIS, BibTeX, JSON.
  • Install, offline, housekeeping
    • Install
      In Chrome, click the Install icon at the right of the address bar. MindMap then has its own window, a Start-menu entry and a taskbar icon; right-click the icon for New map and Tutorial.
    • Offline
      After the first start the app is kept on this computer and opens without internet. Only Crossref lookups need a connection. When a new version is published, a bar offers to restart into it.
    • Diagnostics
      The pulse button in the toolbar: map health, speed, the file you are saving into, autosave copies, Crossref cache, storage used, and which browser features are available.
    • Settings
      The gear button: your e-mail for faster Crossref lookups (optional), font, and the maximum label width on the map.
